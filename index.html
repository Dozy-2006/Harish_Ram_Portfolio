Attendance Management System — Architecture

The system was built to eliminate manual register discrepancy in academic environments with automated CSV rosters, cryptographic authentication, and low-latency MySQL queries.

Multi-Tier Architecture Diagram:

[ Client Web Browser ]
        │  (HTTPS / Cookie Session)
        ▼
[ Gunicorn WSGI Server ]
        │
        ▼
[ Flask Application Router ]
   ├── /auth (Salted Hash Verification & OTP Generator)
   ├── /admin (Department Audit & Tutor Assignment)
   ├── /tutor (Daily Roll Call & Percentage Computation)
   └── /reports (Pandas + OpenPyxl CSV/XLSX Engine)
        │
        ▼
[ MySQL Relational Database ]
   ├── users (id, email, password_hash, salt, role)
   ├── tutors (id, user_id, department, class_assigned)
   ├── students (id, roll_no, name, dept_id)
   ├── attendance_logs (id, student_id, date, status, tutor_id)
   └── otp_tokens (id, email, otp_code, expires_at)
        │
        ▼
[ SMTP Mailer Service ] ──> (Dispatches alerts when attendance < 75%)

Key Engineering Decisions:

  • Salted Password Hashes: Replaced plaintext authentication with PBKDF2 HMAC-SHA256 salted keys to prevent rainbow table attacks.
  • Batched CSV Processing: Utilized Pandas vectorization rather than row-by-row iteration for processing semester attendance imports of 1,000+ students in sub-second time.
  • Gunicorn WSGI: Configured multi-worker concurrency behind reverse proxy for high reliability during peak morning roll-call hours.

Implementation snippet for automated attendance calculation and CSV generation with Pandas: 

import pandas as pd
from openpyxl.styles import PatternFill

def generate_department_report(dept_id: str, db_connection):
    query = """
        SELECT s.roll_no, s.name, 
               COUNT(a.id) as total_days,
               SUM(CASE WHEN a.status = 'PRESENT' THEN 1 ELSE 0 END) as days_present
        FROM students s
        LEFT JOIN attendance_logs a ON s.id = a.student_id
        WHERE s.dept_id = %s
        GROUP BY s.id, s.roll_no, s.name
    """
    df = pd.read_sql(query, db_connection, params=[dept_id])
    df['attendance_pct'] = (df['days_present'] / df['total_days'] * 100).round(2)
    df['defaulter_flag'] = df['attendance_pct'] < 75.0

    # Export to formatted Excel workbook
    output_path = f"/tmp/reports/{dept_id}_attendance.xlsx"
    with pd.ExcelWriter(output_path, engine='openpyxl') as writer:
        df.to_excel(writer, sheet_name='Summary', index=False)
    return output_path

Deterministic state-machine transitions handling language detection, intent categorization, and transit routing: 

class CivicChatEngine:
    INTENTS = {
        'ROUTING': ['route', 'bus', 'reach', 'பாதை', 'பேருந்து'],
        'PARKING': ['park', 'vehicle', 'bike', 'கார்', 'பார்க்கிங்'],
        'EMERGENCY': ['help', 'hospital', 'police', 'மருத்துவமனை']
    }

    def process_message(self, user_msg: str, session_lang: str):
        detected_intent = self.resolve_intent(user_msg.lower())
        if detected_intent == 'ROUTING':
            return self.handle_route_lookup(user_msg, session_lang)
        elif detected_intent == 'PARKING':
            return self.fetch_nearest_parking(session_lang)
        elif detected_intent == 'EMERGENCY':
            return self.trigger_emergency_hotlines(session_lang)
        return self.fallback_prompt(session_lang)
